MODERATION · 世界牆審核

世界牆審核台

牆是「先顯示、後審核」：送出即上牆，這裡處理的是被回報、被自動下架、或名字被過濾掉的那些。
被回報 3 次會自動下架，等你在這裡複查後再決定要不要放回去。

還沒接上 Supabase

請先在 config.js 填入 SUPABASE_URL 與 SUPABASE_ANON_KEY （Supabase 專案 → Settings → API）。
只能填 anon / publishable key，service_role key 絕對不要放進去。

登入

用 Supabase Auth 的帳號登入。帳號要另外被加進 moderators 表才有權限， 光是登入不會自動變成管理員。

打卡列表

「需要處理」= 被回報過、已被下架、或名字被自動過濾掉的。日常只看這一欄就夠。

暱稱封鎖字

命中的暱稱會被清成空白，那筆打卡照樣留在牆上，只是不顯示名字 — 刻意不給使用者錯誤訊息， 免得變成「怎麼規避」的教學。比對前會先轉小寫並去掉空白與標點，所以 a.d.m.i.n 這種寫法也擋得到。
清單預設是空的：請依實際遇到的狀況自己補，不要預先把髒話清單寫進公開的 repo。
第一次設定：Supabase → Authentication → Users → Add user 建一個帳號， 然後到 SQL Editor 執行 insert into public.wall_moderators (user_id) values ('<那個帳號的 uid>');
這一頁只有審核功能，不會顯示 IP、email 或任何統計以外的個人資料 — 因為資料庫裡本來就沒有存。
